competitive\-exam preparation while keeping the application lightweight,
privacy\-friendly and easy to use\.

## Development principles

The project will continue to follow these principles:

1. **Practical first** — features should solve a real study\-planning
   problem\.
2. **Privacy\-friendly** — user study data should remain local unless
   an explicit future feature clearly requires otherwise\.
3. **Lightweight** — avoid unnecessary frameworks and dependencies\.
4. **Mobile\-friendly** — the application should remain usable on
   phones and tablets\.
5. **Transparent development** — planned features should not be
   presented as completed features\.
6. **Backward compatibility** — changes should avoid unnecessarily
   breaking existing study data\.
7. **Real\-world testing** — important features should be tested
   before being marked complete\.

## Status legend
